# Memory Hub 项目基线与来源索引

本文件用于跨 Codex 窗口交接。开始任何产品、界面、交互或发布任务前，应先读取根目录 `PRODUCT.md`、`DESIGN.md`，再按本文件定位详细来源。

## 决策优先级

出现冲突时按以下顺序处理：

1. 用户在项目窗口中明确确认、否决或补充的结论。
2. Figma 中已经确认的正式页面、正式组件与设计变量。
3. `PRODUCT_SPEC.md`、`docs/ADHD_DESIGN_ROADMAP.md`、`docs/DESIGN_REFERENCES.md` 和 `PROGRESS.md` 中标记为已确认或正式的记录。
4. 当前产品代码与自动测试。
5. 研究稿、提案、实验版与参考案例。

当前代码只能证明“现在实现了什么”，不能反过来覆盖更高优先级设计决定。发现冲突时先记录并核对，禁止静默选择实现最方便的一方。

## 已确认的软件基础

- 名称：Memory Hub。
- 定位：本地优先的个人记忆与生活信息管理工具，不是医疗、诊断或效率评分工具。
- 正式一级导航：首页、日历、分类、我的。
- 首页今日事项是日历中今天的投影；完成和无视更新同一事项，删除只从日历软删除。
- 分类只管理文档；冰箱与物品位置从首页进入独立模块。
- 外部 Codex 信息先进入待收录，用户确认后才写入正式数据。
- Android 是当前真实设备反馈与正式发布重点；分支先做 Android 35 预检，`master` 才触发正式签名发布。

完整功能规则见 `PRODUCT_SPEC.md`，当前闭环与验证记录见 `mobile/README.md` 和 `PROGRESS.md`。

## 已确认的主题与外观

- 当前唯一正式视觉基线：冷白底、低饱和彩虹颗粒、深墨蓝文字、通透光学玻璃。
- 颗粒是全局环境层；页面和卡片不得各自绘制不同彩虹渐变。
- 玻璃必须有背景透过、受控模糊、折射亮边、轻内阴影和方向性反光；不得退化成乳白亚克力。
- 信息层级安静清晰，避免卡片套卡片和所有区域同时发亮。
- 历史深色极光主题目前仅为研究，不能自动恢复到正式产品。
- Figma 使用 Inter / Noto Sans SC；Flutter 中文界面以 Noto Sans SC、Microsoft YaHei、系统 sans-serif 回退。
- 动效用于状态与空间关系，通常 140–220ms、ease-out；支持系统移除动画。

实现 token 与组件规范见根目录 `DESIGN.md`；设计借鉴与改造理由见 `docs/DESIGN_REFERENCES.md`。

## 历史讨论中已经确认的关键结论

- 首页存在事项时，日期、今日事项层级与大卡共同占据首屏；文档提醒需向下滚动才出现。
- 卡片不常驻“完成/无视”按钮或教学文案；左右换事项，上滑完成，下滑无视，并提供无障碍替代操作。
- 时间位于主卡上半部并居中，未设置时间显示“全天”；标题与可选备注沿中轴排列。
- 侧卡必须是真实相邻事项且明显更小，不能用同尺寸卡或彩色色块伪装。
- 首页事项卡的真实 3D 反馈由触点驱动：左右、上下、斜向均产生连续双轴倾斜，高光同步移动，松手回正；不能破坏横向换事项与纵向动作。
- 日历必须在拖动过程中同时看到相邻月份：前月、当前月、后月三卡同步移动；未过阈值回弹，过阈值邻月落位。
- 公共玻璃不是“降低白色透明度”：必须统一修正背景透射、模糊、边缘折射、内暗边和方向性反光，并控制整体亮度。
- 界面文案只写对象、状态、动作和必要风险；设计理由、产品原则与自我解释留在规格文档。

## 研究稿与实验版隔离

- Figma 深色极光主题、Behance 参考和主题研究页都是证据或方向对比，不是可直接复制的模板。
- `mobile/lib/main_lab.dart` 和 `mobile/lib/lab/` 属于独立 ADHD 实验版；包名、数据库和验收均与正式版隔离。
- `docs/ADHD_DESIGN_ROADMAP.md` 中的后续功能只有在标记正式且用户要求实现时才进入产品；不能因为实验版已有代码就自动并入正式应用。

## Android 验收基线

- 本地：Flutter analyze、完整非视觉测试、视觉 Golden，并人工查看首页、分类、日历。
- 云端：临时分支运行 GitHub Actions Android 35 预检，构建 APK、执行真实手势/状态断言、保存截图与启动证据。
- 正式发布：预检与人工验图通过后才更新文档、合并或推送 `master`，等待固定签名 Release，再核对 APK 与 manifest SHA-256。
- 不要求为日常验收修改 Windows 虚拟化、安装本机模拟器驱动或连接 USB 手机；仓库历史稳定路径是 GitHub Actions。

## 开始任务前的最小检查

1. 运行 `git status --short --branch` 和 `git diff`，保护尚未提交的修改。
2. 阅读 `PRODUCT.md`、`DESIGN.md` 和本文件。
3. 阅读任务涉及模块的现有代码、测试和 `PROGRESS.md` 最近记录。
4. 涉及 Figma 时核对正式节点身份；研究稿不得混入。
5. 改动公共主题或玻璃后，必须更新相关 Golden 并人工看图。
