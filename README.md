# Memory Hub iOS

Memory Hub 是一个本地优先的个人记忆与生活信息管理应用。产品规则以 `PRODUCT_SPEC.md` 为准，Figma 与设计交接以 `PROGRESS.md` 为准。

## 当前开发基线

- 原生 SwiftUI
- iOS 17+
- Swift 5.9
- 本地版本化 JSON 数据文件，原子写入
- XcodeGen 工程描述：`project.yml`
- 不依赖账号、服务器或第三方运行时

## 在 Mac 上启动

当前仓库是在 Windows 环境建立的，无法在本机运行 Xcode 编译。复制到装有 Xcode 的 Mac 后，可直接打开：

```bash
cd "/path/to/Memory Hub"
open MemoryHub.xcodeproj
```

仓库同时保留 `project.yml`。工程结构变化较大时，可安装 XcodeGen 后用 `xcodegen generate` 重新生成工程。

选择一个 iOS 17 或更高版本的 iPhone 模拟器运行。应用第一次启动时会在 Application Support 下创建 `MemoryHub/memory-hub-v1.json`。

## 已完成的第一阶段闭环

- 四栏主导航与深浅语义主题
- 稳定的系统默认分类
- 新增分类
- 分类进入文档列表
- 文档创建后进入空文档
- 文档标题修改与软删除
- 文档列表编辑状态加入/移出首页提醒池
- 首页从提醒池随机抽取最多三篇，打开首页或主动刷新时重抽
- 新增记录草稿自动保存
- 正式记录的编辑草稿不覆盖原文，点击完成后才发布并写入历史版本
- 放弃新增草稿与放弃编辑草稿
- 正式记录软删除
- 设置页切换跟随系统/深色/浅色
- 长按分类进入管理模式，支持排序、重命名、改色、新增和两种含文档删除策略
- 日历事项新增与编辑，标题必填、时间可选
- 日历事项完成、无视、软删除，以及首页同一事项的完成/无视与短暂撤销
- 统一回收站按分类、文档、记录和日历事项展示，支持恢复和二次确认永久删除
- 文档提醒支持今天隐藏、延后最多 24 小时、永不提醒，以及设置页候选池管理
- 周期事项规则支持每日或指定星期、可选结束日期、停止未来生成与回收站恢复
