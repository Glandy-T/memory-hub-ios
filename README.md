# Memory Hub iOS

Memory Hub 是一个本地优先的个人记忆与生活信息管理应用。产品规则以 `PRODUCT_SPEC.md` 为准，Figma 与设计交接以 `PROGRESS.md` 为准。

## 当前开发基线

- 原生 SwiftUI
- iOS 17+
- Swift 5.9
- 本地版本化 JSON 数据文件，原子写入
- XcodeGen 工程描述：`project.yml`
- 不依赖账号、服务器或第三方运行时

## 在 Mac 上启动

当前仓库是在 Windows 环境建立的，无法在本机运行 Xcode 编译。复制到装有 Xcode 的 Mac 后，可直接打开：

```bash
cd "/path/to/Memory Hub"
open MemoryHub.xcodeproj
```

仓库同时保留 `project.yml`。工程结构变化较大时，可安装 XcodeGen 后用 `xcodegen generate` 重新生成工程。

选择一个 iOS 17 或更高版本的 iPhone 模拟器运行。应用第一次启动时会在 Application Support 下创建 `MemoryHub/memory-hub-v1.json`。

## 自动编译

仓库包含共享 `MemoryHub` Scheme 和 GitHub Actions 工作流 `.github/workflows/ios-build.yml`。推送到 `master`/`main` 或提交 Pull Request 时，会在 GitHub 的 `macos-15` runner 上使用 Xcode 16.4 编译 iOS Simulator 版本；手动触发工作流时还会启动 iPhone 16 模拟器，安装应用并上传浅色、深色首页截图。该检查不需要开发者证书，也不会签名或发布应用。

Windows 本地仍不能执行 Swift/Xcode 编译。GitHub Actions 首次成功只代表工程通过编译；交互、通知、文件面板和视觉效果仍需后续在真实 Xcode 模拟器或设备上验收。

当前状态：提交 `eef44ed` 已在 GitHub Actions 使用 Xcode 16.4、iOS 18.5 Simulator SDK 完成 Debug clean build、安装启动与双主题截图，第一版源码具备真实 Xcode 运行记录。

模拟器视觉冒烟也已通过：手动工作流 `30795764710` 完成 iPhone 16 安装、启动和双主题截图。首页按 Figma 节点 `7:1236` 的 430×932 画板比例实现：主卡 310×548，侧卡 170×438，12pt 间距并左右同时露出；Figma 提案节点 `330:55` 定义卡片上半部 48pt Regular 浅色时间、居中事项标题和可选备注。未设置时间时原位显示“全天”，未填写备注时标题下方不保留占位。侧卡不使用彩色色块占位，卡底不常驻手势教学。在其他设备上按屏幕宽度等比缩放。首页不常驻“完成 / 无视”按钮，左右滑动切换事项，上滑完成、下滑无视；方向反馈只在实际纵向拖动时出现。文档提醒位于首屏之后，需向下滚动才会出现。底栏使用与 Figma 对齐的无文字悬浮材质胶囊。浅色颗粒和苹果玻璃材质属于后续已确认的主题覆盖，不退回旧深色稿的纯蓝实色卡。截图工作流通过专用启动参数注入 3 条示例事项以验收轮播；普通启动不包含示例数据。

## 已完成的第一阶段闭环

- 四栏主导航与深浅语义主题

- 放弃新增草稿与放弃编辑草稿
- 正式记录软删除
- 设置页切换跟随系统/深色/浅色

- JSON 本地备份导入/导出、存储概览和本地通知设置
- 浅色首页颗粒主题资源已加入 Asset Catalog
