# Product

## Register

product

## Platform

web

## Users

Memory Hub 首先服务于产品拥有者本人：在手机上快速回看日程、文档与生活信息，并接收其他 Codex 任务整理出的预约、清单和资料。使用往往发生在移动途中或需要迅速确认信息时，因此界面必须安静、直接，并允许事后修正。

## Product Purpose

提供一个可安装到 iPhone 或 Android 主屏幕的本地优先入口。在没有 App Store 分发条件时仍能使用核心信息，并通过“待收录”队列安全承接外部工具提交的数据。成功意味着用户不必复制粘贴整理结果，同时任何外部写入都不会未经确认污染正式数据。

## Positioning

Memory Hub 把散落在不同任务和生活场景里的信息，变成由用户最终确认、可恢复、可继续维护的个人记忆。

## Brand Personality

安静、清晰、可信。语气使用普通中文，不催促，不拟人化系统，不用效率评分制造压力。

## Anti-references

- 不做聊天机器人界面或 AI 控制台。
- 不做 KPI 仪表盘、连续签到、积分和生产力评分。
- 不使用通用 SaaS 卡片网格、霓虹渐变或厚重磨砂。
- 不让外部任务直接覆盖正式数据，也不隐藏来源和变更内容。

## Design Principles

1. 正式数据由用户做最后决定；外部内容先进待收录。
2. 今日事项是首页焦点，跨任务入口保持次级但易找到。
3. 同一概念在 Web、Android 与保留的 iOS 工程中使用同一名称和数据语义。
4. 本地操作先响应；联网同步属于可替换的传输层。
5. 删除可恢复，导入可追踪，重复提交不得产生重复内容。

## Accessibility & Inclusion

支持系统字体缩放、键盘操作、清晰焦点、至少 44px 触控目标、减少动态效果和足够文字对比度；状态不能只依赖颜色表达。
