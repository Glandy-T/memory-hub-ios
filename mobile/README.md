# Memory Hub Mobile

Flutter 跨平台客户端。Android 是当前真实设备反馈端；`ios/` 保留同一工程目标，后续在 Mac 上完成编译、签名与真机验收。

Android 最低版本为 Android 7.0（API 24），用于支持系统文档导入/导出面板。

## 本地工具

此 Windows 工作区使用仓库根目录下被 Git 忽略的 `.tooling/` 保存 Flutter、JDK 与 Android SDK，不要求全局安装。

## 验证

```powershell
..\.tooling\flutter\bin\flutter.bat analyze
..\.tooling\flutter\bin\flutter.bat test
```

Android SDK 许可证必须由用户本人阅读并接受，之后才能执行真机 APK 构建。

## 隔离的 ADHD 实验版

实验版入口为 `lib/main_lab.dart`，Android 包名为 `com.glandy.memoryhub.lab`，桌面名称为“Memory Hub 实验版”。它使用独立数据库与实验状态键，可与正式版同时安装；普通 `lib/main.dart` 构建不包含实验入口。实验版包含快速记录与待收录、任务拆解、单步专注、暂停检查点、容量时间线、温和重排、常用流程和关联记忆。

```powershell
$env:MEMORY_HUB_LAB_BUILD='true'
..\.tooling\flutter\bin\flutter.bat build apk --release --no-pub -t lib/main_lab.dart
```

GitHub 的 `Android Lab Build` 会独立执行分析、测试和 APK 构建，在 Android 35 实际操作首启、快速记录、待收录、拆解、专注暂停与时间线，再检查 Release 安装启动、前台焦点和致命日志，最后上传 `memory-hub-android-lab` 及启动证据。带 `[lab-only]` 的提交不会触发正式 Android Release 工作流。

仓库的 `Android Build` 工作流会在 Linux runner 上执行依赖解析、静态检查、自动测试并生成优化后的可安装 APK；产物名为 `memory-hub-android-feedback`，保留 14 天。本地 Android SDK 尚未接受许可证时，也可先用该产物进行安卓真机反馈。`master` 的正式构建使用固定发布签名并自动更新 GitHub Release；其他分支只生成隔离的预检产物，不发布应用内更新。

工作流还会在 Android 35 模拟器上先覆盖安装签名升级对，再实际执行主页事项卡触控倾斜、日历横向拖动与换月落位；拖动中帧、落位帧和启动截图作为 artifact 保存。随后清装当前 release APK，直接启动主 Activity，确认应用进程与前台 Activity、扫描 Fatal Exception，并拒绝 Quickstep 或无响应系统弹窗。只有真实手势和干净启动全部通过后才上传建议安装的 APK。

## 当前原生闭环

- 正式版四栏底部导航使用克制的状态动效：选中图标内部彩色分区拼合并轻微聚焦，页面以短距离淡入淡出切换，未选中项保持安静；系统“移除动画”开启时即时切换，四项均保留 48×48dp 触控目标和 TalkBack 语义。
- 首页今日事项：横向真实卡片、随触点变化的轻量 3D 透视、松手回正、上滑完成、下滑无视、撤销与凌晨 4 点日期边界。透视反馈不抢占横向分页，减少动态时关闭。
- 日历：按日查看、新增事项，时间和备注可选；月份卡片支持横向跟手拖动、阈值回弹与方向一致的换月入场。截止日与当日安排使用一致的清晰条目层级，周期规则按查看日期投影，操作后保留独立历史。已完成或已无视的事项、已完成截止日可重新设为待处理。
- 系统通知：有时间的事项可选普通或最多 6 次强提醒；完成、无视或删除会取消后续通知。“我的”可设置每日 8:00/9:00 检查提醒和强提醒间隔。
- 分类、文档与记录：分类管理、提醒池选择、文档重命名/移动分类/归档/软删除，以及记录编辑、版本留存和软删除。
- 记录输入草稿自动持久化，发布后清除；历史正文可回看，长记录可展开/收起。
- 首页文档提醒：有效池随机三篇、主动刷新、打开原文档、今天隐藏、延后最多 24 小时及移出提醒池。
- 全局搜索：分类、活跃/归档文档、正式记录、冰箱、待采购和物品位置。
- “我的”：文档提醒池管理，以及事项、分类、文档、记录和物品位置的统一回收站恢复/永久删除。
- 归档文档独立查看与恢复，不与回收站混用。
- 冰箱内容支持新增与编辑、冷藏/冷冻、开封、可清除的到期日、备注，以及“用完后加入待采购”；移除原因与时间进入 15 天历史，期间可恢复。采购勾选后提供即时撤销，避免误触后条目直接消失。
- 物品位置使用自由文本，不强制固定区域；支持容器、状态、编辑和真实位置变化历史；较长历史在可拖动、可滚动的面板中查看。
- schema v8 本地 JSON 数据库：写入确认后再更新界面，保留上一份可解析备份，损坏时隔离原文并恢复或停止写入。
- “我的 → 数据备份”可通过 Android/iOS 系统文件面板保存或选择完整 JSON，也保留剪贴板应急通道；导入会限制异常大文件、先校验并显示数据摘要，用户二次确认后才替换当前数据。高版本或损坏备份不会改变现有数据库。
- “我的 → 待收录”接入其他 Codex 任务的私有候选队列。首次在已登录 Web 的“我的 → 连接 Android”打开二维码，再在 Android 点“扫码连接”即可；文件选择仅作为备用。凭证保存于 Android Keystore / iOS Keychain，不写入普通数据库、备份或 APK。启动时先读取本地连接并进入界面，再在后台同步；回到前台、打开页面或下拉时也会刷新，网络异常不会阻塞启动。
- 待收录支持先修改标题、备注、文档分类、日期时间（含改回全天）、数量、冷藏/冷冻或自由文本位置，再接受或忽略。外部文档可按分类名称自动匹配，也可在收录前手动选择；稳定候选编号保证重试不会重复创建。

尚未闭环：主题切换。系统文件面板与待收录连接均已接入并通过自动化逻辑/组件测试；Android 原生面板仍需在反馈包真机点击验收，iOS 面板留待可交互 Mac 或真机验证。
