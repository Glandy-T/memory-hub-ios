# Memory Hub Mobile

Flutter 跨平台客户端。Android 是当前真实设备反馈端；`ios/` 保留同一工程目标，后续在 Mac 上完成编译、签名与真机验收。

Android 最低版本为 Android 7.0（API 24），用于支持系统文档导入/导出面板。

## 本地工具

此 Windows 工作区使用仓库根目录下被 Git 忽略的 `.tooling/` 保存 Flutter、JDK 与 Android SDK，不要求全局安装。

## 验证

```powershell
..\.tooling\flutter\bin\flutter.bat analyze
..\.tooling\flutter\bin\flutter.bat test
```

Android SDK 许可证必须由用户本人阅读并接受，之后才能执行真机 APK 构建。

仓库的 `Android Build` 工作流会在 Linux runner 上执行依赖解析、静态检查、自动测试并生成优化后的可安装 APK；产物名为 `memory-hub-android-feedback`，保留 14 天。本地 Android SDK 尚未接受许可证时，也可先用该产物进行安卓真机反馈。当前反馈包使用临时调试签名，仅用于个人测试，不是应用商店发布包。

工作流还会将同一个 APK 安装到 Android 35 模拟器，从启动器打开，等待 10 秒，关闭模拟器残留系统弹窗，并确认应用进程存活、当前焦点属于 Memory Hub 且日志没有应用 Fatal Exception；启动截图和 `logcat` 作为单独 artifact 保存。只有真实启动检查通过后才上传建议安装的反馈 APK。

当前系统文件备份版由 Android Build `31250022479` 验证通过。APK：`.artifacts/android-31250022479/memory-hub-android-feedback/app-release.apk`；SHA-256：`3AE2E48CAA88B5E02ABFA8DE802CD5339295B8D6E6B0B8378E604AE3CF729CE7`。

## 当前原生闭环

- 首页今日事项：横向真实卡片、上滑完成、下滑无视、撤销与凌晨 4 点日期边界。
- 日历：按日查看、新增事项，时间和备注可选；周期规则按查看日期投影，操作后保留独立历史。
- 系统通知：有时间的事项可选普通或最多 6 次强提醒；完成、无视或删除会取消后续通知。“我的”可设置每日 8:00/9:00 检查提醒和强提醒间隔。
- 分类、文档与记录：分类管理、提醒池选择、文档重命名/归档/软删除，以及记录编辑、版本留存和软删除。
- 记录输入草稿自动持久化，发布后清除；历史正文可回看，长记录可展开/收起。
- 首页文档提醒：有效池随机三篇、主动刷新、打开原文档、今天隐藏、延后最多 24 小时及移出提醒池。
- 全局搜索：分类、活跃/归档文档、正式记录、冰箱、待采购和物品位置。
- “我的”：文档提醒池管理，以及事项、分类、文档、记录和物品位置的统一回收站恢复/永久删除。
- 归档文档独立查看与恢复，不与回收站混用。
- 冰箱内容支持新增与编辑、冷藏/冷冻、开封、到期日、备注，以及“用完后加入待采购”；移除原因与时间进入 15 天历史，期间可恢复。
- 物品位置使用自由文本，不强制固定区域；支持容器、状态、编辑和真实位置变化历史。
- schema v8 本地 JSON 数据库：写入确认后再更新界面，保留上一份可解析备份，损坏时隔离原文并恢复或停止写入。
- “我的 → 数据备份”可通过 Android/iOS 系统文件面板保存或选择完整 JSON，也保留剪贴板应急通道；导入会限制异常大文件、先校验并显示数据摘要，用户二次确认后才替换当前数据。高版本或损坏备份不会改变现有数据库。
- “我的 → 待收录”接入其他 Codex 任务的私有候选队列。首次在已登录的 Web“我的”下载 Android 连接文件并导入即可；凭证保存于 Android Keystore / iOS Keychain，不写入普通数据库、备份或 APK。以后启动、回到前台、打开页面或下拉时自动同步。
- 待收录支持先修改标题、备注、日期时间、数量、冷藏/冷冻或自由文本位置，再接受或忽略。接受后按候选类型写入日历、文档、待采购、冰箱或物品；稳定候选编号保证重试不会重复创建。

尚未闭环：主题切换。系统文件面板与待收录连接均已接入并通过自动化逻辑/组件测试；Android 原生面板仍需在反馈包真机点击验收，iOS 面板留待可交互 Mac 或真机验证。
